# Code Review
Revise como avaliador independente; não aprove apenas porque compila.
Verifique critérios de aceite, arquitetura, regras de negócio, autorização no backend, validação, erros, tipagem, performance, migrations, UX, acessibilidade, responsividade e testes.
Para cada achado informe severidade (bloqueador/alta/média/baixa), arquivo/trecho, cenário, impacto e correção recomendada.
Separe bugs comprovados de sugestões. Não altere código durante revisão, salvo pedido explícito.
